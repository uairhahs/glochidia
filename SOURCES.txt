# Source Code Provenance

This file documents the original source code used to compile the third-party binaries
distributed by this project. Glochidia's own tools (gpm, set_locale) are built from this
repository and licensed MIT OR Apache-2.0 (see COPYING).

Versions below are those of the current release; manifest.json in each release is the
authoritative record of the version it ships.

## Format
Each line follows the format:
```
TOOL_NAME | VERSION | LICENSE | SOURCE_URL | SOURCE_SHA256 | STATUS
```

## Build Instructions

All binaries are compiled statically (unless functionality is tested on target) from the above sources using the build scripts in this repository:
- Alpine Linux 3.24 (musl libc) for C/C++ and Rust programs: see container-build.sh
- Debian bookworm (glibc) for msedit, which is dynamically linked: see the build-rust-gnu job
  in .github/workflows/build-release.yml

The complete build process is automated in grow_glochidium.sh and can be reproduced using:
```bash
GIT_REF=<tag_or_commit> SOURCE_SHA256=<tarball_sha256> \
  ./grow_glochidium.sh <source_url> <tool_name> [build_command]
```
